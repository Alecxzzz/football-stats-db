CONECTARSE
----------
  mongosh "mongodb://localhost:27017/threesixtybets_db"

  Si ya se esta dentro de mongosh:
  use threesixtybets_db

  Comandos generales utiles:
  show collections                                    -> lista las 12 colecciones
  db.getCollectionNames().sort()                      -> lo mismo, ordenado
  db.getCollectionNames().sort().forEach(c => print(c, db.getCollection(c).countDocuments()))

ESTRUCTURA DE CADA FICHA
------------------------
  QUE GUARDA  : de donde sale el documento
  CLAVE       : campo natural del upsert (el que evita duplicados)
  INDICE      : indice que aprovecha la consulta
  CONSULTAS   : cada linea trae "->" con lo que hace y lo que devuelve hoy

Las cifras marcadas como "->" son las de esta base el 25/11/2026. Si el visor
se sigue usando, los partidos y el log crecen y los numeros suben.

                                                       formacion_visita: 1, titulares: 1 }));

  // un pais: catalogo, equipos y partidos guardados

  db.LigasSoportadas.find({ pais: 'ESP' }, { _id: 0, nombre: 1 }).count();
  db.Equipos.find({ pais: 'ESP' }, { _id: 0, nombre: 1 }).count();

  // el derivado Paises contrastado con Equipos mediante $lookup
  db.Paises.aggregate([
    { $match: { pais: { $in: ['ESP', 'ENG'] } } },
    { $lookup: { from: 'Equipos', localField: 'pais',
                 foreignField: 'pais', as: 'docs' } },
    { $project: { _id: 0, pais: 1, equiposDeclarados: '$equipos',
                  equiposEncontrados: { $size: '$docs' } } }
  ])
  -> ENG 138/138 y ESP 8/8: el numero que guarda Paises coincide con los
     documentos reales de Equipos para ese pais.

  La idea que se explica aqui: el mismo dato se ve en la web, se pide por
  HTTP y se consulta en mongosh, porque todo sale del mismo almacen.
